title: ways to use it
description: from one person on a laptop to a whole community
---

The box is the same everywhere. What changes is where the runner lives and who is allowed to type.

| you are | you set up | what happens when someone types in the box |
| --- | --- | --- |
| [building an app on your laptop](/start-here) | `<Computah />` and `computah -- next dev` | the code on your laptop changes, and hot reload shows it in seconds |
| [using a personal app every day](/serve-it) | the app on a small always-on machine, `computah serve`, you as owner | the app changes for you from any device, phone included |
| [sharing an app with family or friends](/people-and-trust) | the same, with them listed as `trusted` | it changes for everyone |
| [running an app for a community](/people-and-trust) | the same, with `members: "everyone"` | each person changes a version of their own. You promote the good ones to everybody |
| [hosting on Vercel](/on-vercel) | a runner on another machine, `release: { push }`, one route in the app | the change is pushed to GitHub and Vercel builds it. Members get a preview link |

The first row is two lines. Every other row is one config file, `computah.config.mjs`, that names your build commands, your owners, and how to tell who is visiting.

If your always-on machine is on [exe.dev](/on-exe-dev), its login already says who each visitor is, so that part of the config is one word.
