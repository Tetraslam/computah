the box is the same everywhere, what changes is where the runner lives and who gets to type. a little table :3

| you're | you set up | when someone types in the box |
| --- | --- | --- |
| [building an app on your laptop](/start-here) | `<Computah />` and `computah -- next dev` | your code changes and hot reload shows it in seconds |
| [using your own app every day](/serve-it) | an always-on machine, `computah serve`, you as owner | it changes for you from any device, phone included |
| [sharing it with family or friends](/people-and-trust) | the same, with them listed as `trusted` | it changes for everyone, and anyone trusted can undo it |
| [running it for a community](/people-and-trust) | the same, with `members: "everyone"` | everyone changes their own version and you promote the good ones |
| [running a public app](/guests) | the same, plus `guests`, `clientOnly()` pieces and ideally a sandbox | strangers change the framed pieces in a version only they see |
| [hosting on vercel](/on-vercel) | a runner on another machine, `release: { push }` and one route in the app | it gets pushed to github and vercel builds it. members get a preview link |

the first row is two lines, and every other row is one config file (`computah.config.mjs`) saying how to build the app, who owns it and how to tell who's visiting. on [exe.dev](/on-exe-dev) that last part is one word cause its login already knows
