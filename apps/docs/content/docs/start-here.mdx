this gets the box into your app on your own machine, where it edits your code and hot reload shows you the result. you need a react app in a git repo, and one of [claude code](https://claude.com/claude-code), [opencode](https://opencode.ai), [codex](https://github.com/openai/codex), [droid](https://factory.ai), [cursor's agent](https://cursor.com/cli) or [devin](https://devin.ai) installed and signed in. computah doesn't come with its own agent, it uses whichever one you already have

that's all it needs on your laptop btw. no config file, no env vars, no api key

## install it

```sh
pnpm add @tetraslam13/computah
```

(or the same with npm, yarn or bun)

## put the box in your app

it can go anywhere. in a next app i put it in the root layout so it's on every page, which is two lines added to the layout you already have:

```tsx title="app/layout.tsx"
import { Computah } from "@tetraslam13/computah";

// ...and inside <body>, after {children}:
<Computah />
```

it's already a client component, so the layout doesn't need `"use client"`. it draws itself inside a shadow root so your styles and its styles never touch each other, and it doesn't depend on anything except react

## run the runner

the box is only the window. the thing that actually hands your words to the agent is called the runner, and the way to start it is to run your dev server through it:

```json title="package.json"
{ "scripts": { "dev": "computah -- next dev" } }
```

whatever you put after the `--` runs alongside it, and stopping one stops the other. it uses the first agent it finds installed (it looks for `claude`, `opencode`, `codex`, `droid`, `cursor`, then `devin`), and if you want a specific one you can say so with `computah --agent codex -- next dev`

## use it

open your app and press `Ctrl+.` (`⌘.` on a mac), or click the tiny window button in the bottom right. type what should be different and press return (shift+return if you want a new line)

while it works you get one line telling you what the agent is doing right now, like "reading page.tsx" or "editing counter.tsx", and the page changes under you as it saves files. there's a steps link if you want to see everything it did and a stop link if you change your mind. when it's finished it tells you what it changed in a sentence or two, and there's an undo right there

## other stuff it does

| | |
| --- | --- |
| knows where you were | the page you were on, any text you had selected, your window size, and anything you pointed at with the "point at it" button all get sent to the agent |
| queues | you can send a bunch of requests in a row and they run one at a time, in order |
| commits | each change is its own commit named `computah: ` plus the start of what you typed. if a change touches a file where you had uncommitted edits it stays uncommitted, so your work and the agent's don't get mixed together. `--no-commit` turns this off |
| cleans up | if a request fails or you stop it, none of its edits are kept |
| undoes carefully | undo won't overwrite anything edited since. if later work touched the same lines it tells you and leaves everything alone |

## if it says the runner isn't running

that means nothing is answering on `127.0.0.1:4821`, which is where the runner listens. start your dev server through `computah` like above and the box will notice on its own, it keeps checking
