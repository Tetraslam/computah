This site carries the same box these cards describe. Its owner uses it to change the cards, and visitors use it to change the framed parts that are theirs. A visitor's change stays in their own version until the owner makes it everyone's.

This list is everyone's version: every change in it was a request typed into the box, and it's read from git when the site is built. Each shows what was typed, who asked, and when, newest first. A change that was undone since stays on the list, crossed out. A change still sitting in someone's own version only shows up in that version.
