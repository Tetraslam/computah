---
title: letting anyone change it
description: letting strangers change chosen pieces of a public app
---

for a public app where people who aren't signed in can change a few chosen pieces, each in a version only they see until an owner promotes it

```js title="computah.config.mjs"
import { clientOnly, exeSandbox } from "@tetraslam13/computah/server";

export default {
  // ...
  guests: { secret: process.env.COMPUTAH_GUEST_SECRET, forgetMs: 24 * 60 * 60 * 1000 },
  trust: {
    owners: ["you@example.com"],
    members: "everyone",
    memberPaths: ["app/playground/*.tsx"],
    // each piece must stay a browser-only component that imports only react
    memberCheck: clientOnly(),
    memberNote: "you can change the framed parts of each page.",
    // for the agent
    memberRules: 'each piece keeps "use client" first, takes no props, and imports only react.',
    memberDailyLimit: 10,
    dailyLimit: 200,
  },
  sandbox: { in: exeSandbox() },
  maxCopies: 6,
};
```

## the parts specific to this

| | |
| --- | --- |
| `guests` | turns it on. opening the box makes you a guest, a random name in a cookie signed with `secret` so nobody can pose as another guest, and otherwise a member like any other. `forgetMs` deletes their version once they've been gone that long |
| `members: "everyone"` | required, otherwise a guest is a visitor and can't do anything |
| `memberCheck: clientOnly()` | refuses a change that stops being a client component (`"use client"` first), declares server code, or imports anything but `react`. `clientOnly({ imports: ["react", "..."] })` lets more through |
| `maxCopies` | personal copies running at once, and one more stops whichever was used longest ago |
| `maxAgents`, `maxBuilds` | how many agents and builds run at once. when a bunch of people ask at the same moment the build is the line they wait in, so if the machine has the cpus, `maxBuilds: 2` about halves it |
| `guests.keep` | only this many guest versions are kept, the oldest-used go first, so the disk can't fill up |

`memberPaths`, `memberNote`, `memberRules` and the limits work like for any member ([people and trust](/people-and-trust)), and `sandbox` is on [sandboxes](/sandboxes)

## why this is safe

- **a guest's code never runs on your server.** you load each changeable piece with `next/dynamic` and `ssr: false`, from a wrapper outside `memberPaths`, and `clientOnly()` rejects a change that stops being a client component, declares server code, or imports anything but `react`
- **a guest's code runs only in their own browser.** their changes live in their own version until an owner promotes one
- **a guest's agent sees only a copy of the code.** with a sandbox it runs on a throwaway machine, without your ignored files
- **costs are capped.** there are per-person and whole-app daily limits and a cap on running copies, and guests who don't come back get cleaned up

a fix for a broken build is held to the same `memberPaths` and `memberCheck` as the change

## this site does exactly this

the "yours to change" windows are files in `apps/docs/playground`, loaded by `apps/docs/components/playground.tsx` with `next/dynamic` and `ssr: false` inside an error boundary, so breaking yours doesn't take the card down. the config is [`computah.docs.config.mjs`](https://github.com/tetraslam/computah/blob/master/computah.docs.config.mjs) at the repo root:

```js title="computah.docs.config.mjs"
guests: guestSecret ? { secret: guestSecret, forgetMs: 24 * 60 * 60 * 1000 } : undefined,
trust: {
  owners: list(process.env.COMPUTAH_OWNERS ?? "you"),
  trusted: list(process.env.COMPUTAH_TRUSTED),
  members: guestSecret ? "everyone" : undefined,
  memberPaths: ["apps/docs/playground/*.tsx"],
  memberCheck: clientOnly(),
  memberNote: "you can change the framed parts of each page. only you see your version.",
  memberRules: "...", // one piece per page, "use client" first, no props, only react
  memberDailyLimit: 12,
  dailyLimit: 150,
},
sandbox: process.env.COMPUTAH_SANDBOX === "exe" ? { in: exeSandbox() } : undefined,
maxCopies: 5,
```
