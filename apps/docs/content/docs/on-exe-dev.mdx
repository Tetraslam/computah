---
title: on exe.dev
description: running it on exe.dev, whose login already knows you
---

[exe.dev](https://exe.dev) is a small always-on machine with a login in front, and its proxy tells the app who's visiting, so the runner needs no sign-in of its own. it's one word in the config:

```js title="computah.config.mjs"
export default {
  app: {
    install: "pnpm install --frozen-lockfile",
    build: "pnpm build",
    start: "pnpm start",
    dev: "pnpm dev",
  },
  identity: "exe",
  trust: {
    owners: ["you@example.com"],
    members: "everyone",
    memberPaths: ["app/**"],
  },
};
```

run `computah serve` on the machine and leave it running (port 8000 unless the config says otherwise)

## how it knows who you are

the proxy sets `x-exedev-userid` and `x-exedev-email` on every signed-in request, which the runner reads as your id and name, so `trust` lists people by email. it also strips those headers from whatever visitors send, which is the only reason they can be believed, so if the runner is reachable any other way anyone can claim to be you. don't use `identity: "exe"` anywhere else

## this repo does it

computah's own demo runs like this, with exe.dev's login there and this-machine-only everywhere else:

```js title="computah.config.mjs"
// How the demo is served with a version per person. Run `pnpm serve` at the repo root.
const owners = (process.env.COMPUTAH_OWNERS ?? "you").split(",").map((entry) => entry.trim());

export default {
  agent: process.env.COMPUTAH_AGENT,
  model: process.env.COMPUTAH_MODEL,
  port: Number(process.env.PORT ?? 8000),
  app: {
    dir: "apps/demo",
    install: "pnpm install --frozen-lockfile && pnpm --filter @tetraslam13/computah build",
    build: "pnpm build",
    start: "pnpm exec next start",
    dev: "pnpm exec next dev",
  },
  // On exe.dev its proxy says who each visitor is. Anywhere else, only this machine counts as you.
  identity: process.env.COMPUTAH_IDENTITY === "exe" ? "exe" : "local",
  trust: {
    owners,
    trusted: (process.env.COMPUTAH_TRUSTED ?? "").split(",").filter(Boolean),
    members: "everyone",
    // Members may change the demo's pages and nothing else.
    memberPaths: ["apps/demo/app/**"],
  },
};
```
