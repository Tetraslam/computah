okay so this is a little window you put in your app. you type what you want to be different, and an agent goes and edits the app's code while you sit there and watch it happen

<Recording />

## how to get it

install it:

```sh
pnpm add @tetraslam13/computah
```

then put the box anywhere in a react app, as long as the app lives in a git repo:

```tsx
import { Computah } from "@tetraslam13/computah";

<Computah />;
```

and run your dev server through computah instead of on its own:

```sh
computah -- next dev
```

open your app, press `Ctrl+.` (`⌘.` on a mac) and type whatever you want changed. it uses the coding agent you're already signed into (claude code, opencode or codex) so there's no account to make and no api key to paste anywhere. the longer version of all this is on [start here](/start-here)

## where this came from

patrick collison [posted](https://x.com/patrickc/status/2116636967517798672) that he's been putting "a freeform text input that's hooked up to an agent that yolo implements whatever is submitted" into all his personal apps, and i wanted that in all of mine without rebuilding it every time. so now it's a library
